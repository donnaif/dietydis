# DietyDis

تطبيق Discord خاص لـ Windows 10 و11 (64-bit)، مبني على **Vesktop** (التطبيق) و**Vencord** (محرك الإضافات).

## محتوى المجلد

| الملف | وظيفته |
|---|---|
| `run-setup.bat` | تشغيل الإعداد كاملاً بضغطتين |
| `setup-dietydis.ps1` | السكربت الفعلي: ينزّل الكود، ينسخ الإضافات، يبني، يغيّر الاسم، يشغّل |
| `scripts/rebrand.mjs` | يحوّل Vesktop إلى DietyDis (الاسم، المعرّف، ملف التثبيت، النصوص الظاهرة) |
| `plugins/` | إضافات DietyDis، وهي المصدر الأساسي. تُنسخ إلى `Vencord\src\userplugins\` |
| `scripts/make-icon.ps1` | يصنع من الشعار كل الأيقونات: `icon.ico` و`tray.png` و`trayUnread.png` و`splash.png` |
| `assets/` | الشعار الأصلي `logo-original.png` والأيقونات المصنوعة منه |

الكود المصدري يُنزَّل إلى `%USERPROFILE%\DietyDis-src\` (مجلد `Vencord` ومجلد `Vesktop`).

## التشغيل

```bat
run-setup.bat              :: بناء وتشغيل DietyDis
run-setup.bat -NoStart     :: بناء فقط
run-setup.bat -Package     :: بناء ملف التثبيت DietyDis-Setup-<version>.exe
```

المتطلبات: Node.js 22 أو أحدث، وGit. أما pnpm فيفعّله السكربت تلقائياً إن لم يكن موجوداً.

### كيف يجد التطبيق Vencord

- **التطبيق المثبّت (من ملف التثبيت):** Vencord مع إضافات DietyDis مدمج داخل التطبيق في `resources\vencord`. لا يُنزَّل شيء من الإنترنت، ويعمل على أي جهاز.
- **أثناء التطوير على جهازك:** السكربت يضبط **Vencord Location** على `Vencord\dist` في `%APPDATA%\DietyDis\state.json`، فترى تعديلاتك فوراً بعد البناء.

Vencord يُبنى بـ `--standalone --disable-updater`، فلا يحدّث نفسه إلى النسخة الأصلية ولا تضيع إضافاتنا. وزر "Repair Vencord" لا ينزّل النسخة الأصلية فوق نسختنا المدمجة.

إضافة **DietyDisArabic** مفعّلة تلقائياً للمستخدمين الجدد.

## نشر نسخة جديدة (التحديث التلقائي)

رقم نسخة DietyDis ومستودع النسخ في `dietydis.config.json`. التطبيق المثبّت يفحص عند كل تشغيل صفحة Releases في هذا المستودع، فإذا وجد نسخة أحدث عرض نافذة التحديث.

لنشر نسخة:

```powershell
.\release.ps1 -Version 1.0.1 -Notes "ما الجديد في هذه النسخة"
```

السكربت يرفع رقم النسخة، ويبني المثبّت، ويعمل commit وtag، ثم ينشر Release على GitHub بالملفات التي يحتاجها التحديث (`.exe` و`.blockmap` و`latest.yml`). يحتاج GitHub CLI مسجّل الدخول (`gh auth login --web`).

مهم: رقم النسخة الجديدة يجب أن يكون أعلى من السابقة، وإلا لن يصل التحديث للمستخدمين.

## الشعار

لتغيير الشعار: ضع صورة PNG مربعة (1024 بكسل أو أكبر) ثم شغّل:

```powershell
.\scripts\make-icon.ps1 -Source assets\logo-original.png
```

يصنع أيقونة بحواف دائرية بكل الأحجام (16 إلى 256)، مع تكبير بسيط في الأحجام الصغيرة، وصورة `icon-preview.png` للمعاينة. ثم أعد `run-setup.bat -Package`.

ملاحظة: إذا كان DietyDis مثبّتاً من قبل، فقد يبقى الشعار القديم في شريط المهام حتى تثبّت النسخة الجديدة فوقه، لأن Windows يأخذ الأيقونة من اختصار قائمة ابدأ.

## إضافة DietyDisArabic

- اتجاه تلقائي للنص: العربي من اليمين لليسار والإنجليزي من اليسار لليمين، في الرسائل والردود والـ embeds وحقل الكتابة.
- خط خاص للحروف العربية فقط (الافتراضي Segoe UI)، دون تغيير شكل الإنجليزي.
- حجم خاص للحروف العربية (80% إلى 150%).

## تطوير الإضافات

عدّل الإضافات داخل `plugins/` ثم أعد تشغيل `run-setup.bat`. وللتطوير السريع:

```bat
cd %USERPROFILE%\DietyDis-src\Vencord
pnpm watch      :: ثم Ctrl+R داخل التطبيق لإعادة التحميل
```

## ما تم تغييره في Vesktop

- الاسم: DietyDis، المعرّف `com.dietydis.app`، الملف التنفيذي `dietydis.exe`.
- ملف التثبيت: NSIS لـ x64 فقط، مع اختيار مجلد التثبيت.
- النصوص الظاهرة: عنوان النافذة، أيقونة الشريط، القوائم، رسائل الأخطاء، ونصوص صفحة الإعدادات (قسم "DietyDis Settings").
- معرّف Windows (AppUserModelId) صار `com.dietydis.app` مثل المثبّت، حتى تعمل الإشعارات وتثبيت التطبيق في شريط المهام.
- الشعار في: الملف التنفيذي، شريط المهام، أيقونة الشريط (وبنقطة حمراء للرسائل غير المقروءة)، وشاشة التحميل.
- **التحديثات من مستودع DietyDis وليس Vesktop**: رقم نسخة خاص (يبدأ من 1.0.0) ونافذة التحديث تقرأ Releases في `donnaif/dietydis`.
- التطبيق المثبّت يحمّل Vencord من `resources\vencord` (`src/main/vencordFilesDir.ts`)، ولا ينزّل Vencord الأصلي (`src/main/utils/vencordLoader.ts`).

## المراحل

**المرحلة الثانية (تمت):** دمج Vencord وإضافاتنا داخل ملف التثبيت (`extraResources`)، وتعطيل كل التحديثات التي تستبدلها بالنسخ الأصلية.

**التالي:**
- توقيع ملف التثبيت حتى لا يظهر تحذير SmartScreen.
